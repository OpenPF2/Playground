# Contributing to OpenPF2Playground

Follow the [OpenPF2 contributor guide](https://github.com/OpenPF2/Plugin/blob/main/CONTRIBUTING.md) for shared Unreal C++ conventions. Match the nearest equivalent file for repository-specific details, preserve public interfaces, and keep changes focused on the requested work.

## Bumping Copyrights

When modifying a project-owned file with a copyright notice, update its end year to the current calendar year in the same commit. Preserve the original start year and copyright holder. Extend a single earlier year to a range, such as `2024-2026`. New project-owned source files should use the current year and the appropriate local license header.

Preserve third-party copyright notices, years, license text, and attribution exactly. Update notices only in files touched by the change, including dependency repositories when applicable. Check all touched notices before committing.

Contributions must use the same license as the existing file. See [LICENSE.txt](LICENSE.txt).
